# Student Performance Prediction Using Machine Learning

## Objective
Predict a student's final academic score using study habits and academic indicators.

## Features
- Hours studied per day
- Attendance percentage
- Previous score
- Assignments completed
- Sleep hours
- Extracurricular activity

## Target
`final_score`

## Machine Learning Models
1. Linear Regression
2. Random Forest Regression

## Workflow
Dataset -> Preprocessing -> Train/Test Split -> Model Training -> Evaluation -> Prediction

## Evaluation Metrics
MAE, MSE, RMSE, R2 Score

## Run
1. Install Python 3.10+.
2. Open terminal in this project folder.
3. Run: `pip install -r requirements.txt`
4. Run: `streamlit run app.py`
5. Open the local URL shown by Streamlit.

## Important viva point
This is an educational demonstration dataset created for the project. It is not intended for real institutional decision-making. In a real deployment, a larger and ethically reviewed dataset should be used.
